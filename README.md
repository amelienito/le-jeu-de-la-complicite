# Le Jeu de la Complicité

Fais deviner un mot à ton pote uniquement avec ce que vous avez vécu ensemble. « Dalida ? — Ta mère est fan. »

Jouer : https://amelienito.github.io/le-jeu-de-la-complicite/

D'après le jeu de l'émission *Un Bon Moment* (Kyan Khojandi et Navo). Site non officiel, sans lien avec l'émission. La boutique : [Une Bonne Boutique](https://unebonneboutique.com/collections/un-bon-moment-1).

- **En ligne** : un code de 4 lettres, pas de compte. Celui qui devine ne voit jamais le mot.
- **Sur un seul téléphone** : on se le passe à chaque tour.
- À 4, deux équipes (Noirs contre Blancs) ; à 2, chacun son tour. On change de tour tous les 5 points.
- On passe n'importe quel mot sans pénalité. À la fin, un indice de complicité sur 100.

## Les fichiers

- `index.html` + `style.css` + `app.js` : le jeu.
- `words.js` : les mots, par thème. Pour en ajouter, c'est là.

En ligne, les téléphones se relient en direct avec PeerJS (licence MIT) : la partie vit chez celui qui l'a créée, qui garde la page ouverte.
